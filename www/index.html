A Modern 64-Bit Hobby Operating System Built from Scratch

Welcome to the LikeOS home page. LikeOS is a modern 64-bit operating system built entirely from scratch, demonstrating contemporary OS development with a complete Unix-like userland.

LikeOS was written by Nikolaos Rangos.

Current development release:

LikeOS 0.2.4-HEAD

Version 0.2.4 has these key features:

  • 64-bit long mode kernel with higher-half mapping.
  • UEFI boot path with framebuffer and memory map handoff.
  • Interrupt and exception handling with IDT and PIC/APIC integration.
  • SMP support for up to 64 CPUs with AP startup using INIT-SIPI-SIPI.
  • Per-CPU data structures, run queues, and scheduler accounting.
  • LAPIC timer setup, IOAPIC routing, TLB shootdown, and SMP-aware locking.
  • Preemptive multitasking scheduler with fork, execve, exit, wait4, signals, and pipes.
  • User mode execution in ring 3 with ELF64 binary loading and #! scripts.
  • ext4 as the root filesystem — read and write, with extents, hash-indexed directories, extended attributes and a journal — plus FAT32, VFS and devfs layers.
  • Demand paging: anonymous memory, brk, BSS and private file mappings are populated on first touch rather than at exec, alongside copy-on-write fork.
  • Dentry cache, inode cache, and page cache with read-ahead and CLOCK-style eviction.
  • Multi-user login: init, getty and login with PAM and yescrypt, users and groups, and file permissions enforced in the VFS.
  • POSIX threads, System V and POSIX shared memory, poll/select/epoll, and PTYs.
  • UTF-8 throughout: the console decodes it and addresses glyphs by code point, and the C library implements the full multibyte and wide-character interface.
  • xHCI USB 3.0 stack and USB mass storage driver.
  • PS/2, I2C-HID, PCI, APIC, and ACPI hardware support; VMware SVGA II graphics with a hardware cursor.
  • TCP/IP networking stack with BSD-style sockets and multiple NIC drivers.
  • Physical and virtual memory management with SLAB allocator, stack canaries, and security protections.
  • Virtual terminals (VTs) with POSIX-like TTY, xterm-compatible escape handling, and signal handling.
  • Userland libc with dynamic runtime linker, dlopen, POSIX regular expressions and iconv.
  • Framebuffer console with scrollback, a scrollbar and a mouse pointer.
  • Core utilities: ls, cat, cp, mv, rm, grep, sed, find, top, ps, and many more.
  • Ported applications: bash 5.2 as the system shell, OpenSSH 10.4 (client and server), OpenSSL, curl, tmux, nano, and netcat.
  • An X.Org desktop: the X server on the framebuffer with the ctwm window manager, xterm, the NetSurf web browser, the XNEdit editor, xcalc, xclock and xload.
  • Real hardware support on Lenovo and Dell notebooks, VMware, VirtualBox, and QEMU.

Trying it. At the login prompt, log in as root with the password toor, then type startx to bring up the X.Org desktop. Button 1 on the desktop background opens the root menu — xterm, xcalc, XNEdit, NetSurf — and “Exit session” returns to the console. Any user can run startx: the X server is installed setuid root and gives root up as soon as it has opened the framebuffer and the input devices, so no group membership is needed.

Building with make SCREEN_SIZE=large asks for a 1920×1200 screen instead of the default 1280×800, falling back through the usual modes if the display cannot do it.

LikeOS is a Unix-like operating system designed to demonstrate modern OS development from the ground up. It features a complete userland with process management, syscalls, preemptive multitasking, symmetric multi-processing (SMP), a multi-user login, and bash as the interactive shell. The system boots via UEFI from an ext4 root filesystem, runs on (some) real hardware as well as virtual machines (QEMU, VMware, VirtualBox), and includes a rich set of core utilities, a C library with dynamic linking support, TCP/IP networking with OpenSSH, and an X.Org desktop.
