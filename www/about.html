About LikeOS

Who builds LikeOS, who holds the copyright, and how to get in touch.

The project

LikeOS is a 64-bit operating system for PCs, built from the ground up: its own kernel, drivers, C library and runtime linker, with a large set of free software ported on top — from bash and OpenSSH to the X.Org desktop, GTK3 and the WebKit browser engine.

The project aims at a system that is genuinely usable on real computers: boot it, log in, and work — mail, chat, files, terminals, music and video, and the modern web. The current development release is 0.2.7-HEAD, developed in the dev branch.

Third-party software

LikeOS includes and builds many free-software projects — among them the X.Org server, Mesa, GTK, GLib, WebKitGTK, luakit, GStreamer, FFmpeg, OpenSSH, OpenSSL, bash, Claws Mail and HexChat.
